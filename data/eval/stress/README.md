# Стресс-срез

Написан **после** того, как правила были зафиксированы и показали 1.00 на
синтетике и рукописном срезе, — и написан специально против них:
формулировки, которых нет ни в шаблонах, ни в примерах правил.

| Файл | Что проверяет |
|---|---|
| st_lease_01 | «1/300 базовой ставки», «73% годовых», «оставляет за собой право», пассив «может быть расторгнут Арендодателем», отказ за нарушение (не риск) |
| st_supply_01 | «100-процентной предоплаты», «корректировать цены», претензии «в момент приемки», «0,5 (ноль целых пять десятых) процента» |
| st_services_01 | штраф в тенге, а не в процентах (25% цены), «90 рабочих дней», «в любое время … за 3 дня» |
| st_lease_kk_01 | «өз қалауы бойынша қайта қарауға», «автоматты түрде тағы бір жылға ұзартылады» |
| st_supply_02 | оплата «по мере реализации конечным потребителям» — поставщик кредитует покупателя без срока |
| st_lease_02_clean | ни одной ловушки, но много «жёстких» нейтральных формулировок: индексация с потолком, удержание долга из депозита, отказ при неуплате |

Этот срез — не заголовочная метрика, а инструмент поиска слабых мест: его
автор знал правила. Он нужен, чтобы показать, где кончается baseline на
правилах и где должны работать ML и LLM.
