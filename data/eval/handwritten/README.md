# Рукописный срез

Шесть договоров, написанных вручную и **другим стилем**, чем шаблоны
генератора: иная нумерация («1.1 » без точки, «Статья N» с внутренними
«1.», «2.»), длинные пункты с несколькими условиями, синонимы
(«депозит», «прайс-лист», «Исполнитель»), формулировки, которых нет ни
в одном шаблоне. Разметка — по docs/LABELING_GUIDE.md, сделана до первого
прогона системы на этом срезе.

| Файл | Тип | Сторона | Что проверяет |
|---|---|---|---|
| hw_lease_01 | аренда | арендатор | 8 находок, включая отсутствие форс-мажора |
| hw_supply_01 | поставка | покупатель | «Статья N» + «1.», претензии «в течение 24 часов» |
| hw_services_01 | услуги | исполнитель | роль «Исполнитель», оплата после оплаты третьих лиц |
| hw_lease_kk_01 | аренда, kk | арендатор | казахский; односторонняя ответственность без неустойки арендодателя |
| hw_supply_02 | поставка | поставщик | перспектива «сильной» стороны: отсрочка оплаты, отказ покупателя |
| hw_works_02_clean | подряд | заказчик | ни одной ловушки: только ложные тревоги |

Персонажи, организации и БИН/ИИН вымышлены (номера — заведомо
недействительные нули).

Ограничение, о котором стоит помнить: автор рукописного среза — тот же,
кто писал руководство и правила. Срез снижает, но не устраняет
оптимизм оценки. Следующий шаг — публичные договоры (см. EVALUATION.md,
«Что дальше»).
