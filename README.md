# kz-contract-risk

Первичный скрининг договоров аренды, поставки и подряда для малого бизнеса
Казахстана: находит рискованные условия и объясняет их простым языком.

Статус: в разработке. План и чекпоинты — [docs/PLAN.md](docs/PLAN.md).

> Это не замена юристу, а первичный фильтр: он показывает, на какие пункты
> стоит обратить внимание до подписания.
